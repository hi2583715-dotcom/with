# Wither Form (Fabric)

Minecraft Java 26.3 / Fabric mod.

## Features
- Use `/witherskull` to receive the custom Wither Skeleton Skull.
- Hold the marked skull in your offhand to transform.
- Creative-style flight (not in Creative or Spectator mode).
- Wither-effect immunity, periodic Resistance, smoke/soul aura, and transformation effects.
- Remove the skull from your offhand to end the form.

## Build
This repository includes a GitHub Actions workflow. Open **Actions → Build Wither Form** and run it. The compiled JAR is uploaded as an artifact when the build succeeds.

Requires Java 25, Minecraft 26.3, Fabric Loader, and Fabric API.
